---
title: Relational Algebra and Higher Dimensional Algebra
date: 2021-08-29
---

We can do relational algebra in prolog,
by writing logic variables and identify
the same logic variables as referring the same thing
(just like in SQL we join over a key).

This means relational algebra is already a algebra
in which we can product two elements along different positons.

We can borrow its syntax into higher dimensional algebra.

- We should do low dimensional algebras first -- 0, 1, 2, 3.

Maybe we can also use higher dimensional algebra
as the type system of logic programming,
to express equivalence between relations.
